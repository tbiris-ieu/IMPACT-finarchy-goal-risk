Finarchy Goal risk check API

Will this savings goal be abandoned before its date?

Finarchy helps young savers reach a goal that has a date on it: a master's, a deposit, a trip. The saver sets the amount and the date, contributes monthly, and the app lowers the investment risk as the date gets closer.

The biggest thing that can go wrong along the way is not a market dip. It is the saver who stops contributing and quietly drops the goal. This tool is Finarchy's early warning for that: enter three facts about a goal and the trained model returns the chance it will be abandoned before its date.

Predicts
goal_abandoned: 1 if the goal is dropped before its goal date, 0 if it stays on track, plus the probability.
Risk area
Customer behaviour risk: savers abandoning their plan. For the saver it means a missed goal; for Finarchy it means lost deposits and a lost customer.
Model
Logistic regression (scikit-learn), trained on 1,000 goals. Test accuracy 79%, AUC 0.87.

What Finarchy does with the result

Each risk band has a clear action inside the app, so the team steps in while the goal can still be saved.

Low risk under 30%
No action needed. The saver keeps the standard monthly reminder.
Medium risk 30 to 50%
A nudge before the next contribution date, showing how close the goal already is.
High risk 50% and over
Flagged for intervention: Finarchy offers a smaller monthly amount or a later goal date, so the saver adjusts the plan instead of giving up on it.

How the model works

The model is a logistic regression trained on 1,000 Finarchy goals, one row per goal. Because the app has no live users yet, the dataset is simulated (see fintech.py). The data was split 70/30 into training and test sets; on the test set the model classifies 79% of goals correctly, with an AUC of 0.87.

InputWhat it does to the risk
Missed contributions in the last 6 months The strongest signal by far. Each missed month multiplies the odds of abandonment by about 2.6.
Months since the goal was created Older goals are a little safer: a goal that is one year older has about 27% lower odds.
Average monthly contribution Bigger contributions are a little safer: every extra 100 EUR a month cuts the odds by about 39%.

For other applications: the API

The same prediction is available as JSON, so other parts of Finarchy (or any other service) can call it. Send the three inputs to POST /api/predict: 

curl -X POST {{ request.url_root }}api/predict \
  -H "Content-Type: application/json" \
  -d '{"months_since_goal_created": 12,
       "avg_monthly_contribution": 150,
       "missed_contributions_last_6_months": 3}'

A GET request with query-string parameters works too, which is handy for testing in a browser: /api/predict?months_since_goal_created=12&avg_monthly_contribution=150&missed_contributions_last_6_months=3

The response contains the inputs, the prediction (0 or 1), both probabilities, the risk band and the recommended action. Invalid or missing inputs return status 400 with an error message. Full details are in the README.

Finarchy is a class project. The model is a prototype trained on simulated data and is not financial advice.
